# Marque Guide·Achat

- **Nom** : toujours « Guide·Achat », avec le point médian. Jamais traduit (`translate="no"` sur le logo).
- **Slogan** : « Bien pour tout le monde ? On préfère bien pour vous. »
- **Mot-symbole** : Archivo 900, approche −0,05 em ; le point est un disque plein (`.ga-wordmark`, `.ga-dot` dans `assets/css/design-system.css`).
  - Accueil : point orange `#FF651B`, encre `#20221E`.
  - Guides : point jaune `#FFD400` cerclé d’encre `#0F1115` (sans cercle en thème sombre).
  - Monochrome : tout à l’encre.
- **Symbole** (`guide-achat-symbole.svg`, `-mono.svg`) : un G ouvert, le point du choix logé dans l’ouverture. Favicon : `favicon.svg` (tuile encre, point orange) ; icône d’application : `apple-touch-icon.png` (180 px).
- **Fond commun** : `#E3E7EB`.
- **Taille minimale** du mot-symbole : 18 px de haut ; en dessous, le symbole seul.

En-tête, recherche et pied de page sont communs à toutes les pages : les modifier dans `tools/site/gabarit.py`, puis lancer `python3 tools/site/gabarit.py`.
